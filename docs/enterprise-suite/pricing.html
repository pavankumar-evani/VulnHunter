VulnHunter Pricing

Priced around a real capability gap, not just a cheaper scan: Professional is the only tier in this market's comparison set that turns a finding into a generated, reviewable fix rather than a ticket — ServiceNow's own documentation confirms its remediation is task-based only (§01). Licensed annually by environment size, unlimited users at every tier, backed by a real support SLA. Normalized to cost-per-asset (§02), VulnHunter also runs 3–5x cheaper than the least-expensive named scanner.

Why the Standard → Professional jump is priced on a real capability gap, not just more assets

ServiceNow's own current Vulnerability Response/USEM documentation describes remediation as a phased task process — "verifying import completion, triaging new vulnerabilities, and monitoring progress to completion" — explicitly ticket/workflow automation, not automated generation of an actual fix artifact. Tenable, Qualys, and Rapid7 don't generate fixes at any price either — they're scanners that feed a ticketing system like ServiceNow. Professional is priced on VulnHunter being the one product in this comparison that turns a finding into a real, reviewable Ansible playbook automatically — a capability gap the competition doesn't close by paying more, not a feature VulnHunter is merely bundling at a higher tier.

03Licensing options

Every option below is a real, current pattern in this market — matched to VulnHunter's own structure, not invented from nothing.

Term-based subscription (standard)

Annual, auto-renewing. Every platform researched for §02 has moved to this model — nobody in vulnerability management sells a perpetual license anymore, and VulnHunter doesn't either.

Per-Endpoint metering (alternative to a flat tier)

$6.50/endpoint/year, no tier commitment, 500-endpoint minimum — priced the same way Tenable, Qualys, Rapid7, and CrowdStrike Spotlight all bill (per unit under management), for an environment whose size varies too much for a flat cap to fit well. Still 3x+ cheaper per unit than every named competitor in §02. "Endpoint" here means the same billable unit as "asset" elsewhere in this document — any host, cloud resource, network device, or application VulnHunter tracks a finding against.

Scan-engine add-on (Standard tier only)

$6,000/year adds the OpenVAS/GVM scan engine to Standard without a full Professional upgrade — the same "core platform + priced add-on module" pattern CrowdStrike uses for Falcon Spotlight. Included by default in Professional and Enterprise. Note: the remediation engine itself (playbook generation) is a Professional-tier capability, not an add-on — see the callout in §01.

Multi-year commitment discount

10% (2-year) / 15% (3-year), prepaid or annual invoicing — deliberately more modest than the 38–45% Qualys reportedly discounts at 3-year/10,000+-asset scale (§02's sourcing), since VulnHunter's list price is already positioned well below that comparison point.

04Vertical modules — OT/IoT & AppSec

OT/IoT and Application Security are different buying centers, different buyers' budgets, and — per the Remediation Engine document's "Four remediation tracks" section — genuinely different remediation mechanisms under the hood. They're priced as separate modules, not folded into the core per-asset tiers, the same way Tenable sells Tenable.ot separately from Tenable.io rather than bundling OT into the same per-IT-asset price.

OT/IoT Security Module

$18,000/year — up to 2,000 OT/IoT devices (add-on to Professional or Enterprise; requires the core remediation engine).

Includes OT-aware risk scoring, the dedicated OT/IoT hub page, and the OT remediation workflow — remediation-fixer-ot generates a compensating-control/vendor-coordination recommendation, never a direct patch script, since OT devices are usually unsafe to patch live. Additional devices: $600 per 100/year.

Honest scope: this is a risk-management and remediation-workflow layer for OT/IoT findings from your existing sources (Tenable/Armis/Axonius/Infoblox) — not a replacement for deep OT-protocol network monitoring (Claroty, Dragos, Nozomi Networks, priced separately and typically quote-only). Designed to sit alongside one, not compete with it.

Application Security Module

$9,000/year — up to 25 applications/repositories (add-on to any tier).

Includes SAST via /vulnhunt with real, working auto-fix: vuln-fixer opens an actual git branch + pull request for mechanical fixes (SQL injection, hardcoded secrets, etc.) — a capability Checkmarx and Veracode don't offer as a core built-in. Also ingests DAST/SCA/Secrets/Container findings (no automated fixer for these yet — same honestly-disclosed gap as network devices, tracked as a real roadmap item). Additional apps: $300/year each beyond 25.

For comparison: Veracode SAST alone lists $15,000–$25,000/year for up to 100 applications; Checkmarx SAST lists $10,000–$15,000/year for the same range. This module is priced well below both while including the auto-fix-PR capability neither ships natively.

Two possible pricing mechanisms for a hosted tier — options for the business to decide between, not a decision made here:

Option A — "VulnHunter Cloud" SKU: license + hosting uplift

Keep every existing license tier unchanged and add a hosting uplift of roughly +15-25%, framed as covering infra/ops/monitoring/on-call — not a firm number. Applied to today's real prices: Standard +$1,800-$3,000/yr (~$150-$250/mo); Professional +$5,700-$9,500/yr (~$475-$792/mo); Enterprise +$12,750-$21,250/yr (~$1,063-$1,771/mo). The uplift is meant to cover more than the raw infra estimate above (staffing, monitoring, margin) — the two numbers aren't meant to match exactly, just sit in the same neighborhood at Professional scale.

Option B — Metered infra pass-through

Bill actual infrastructure (compute + database + storage + egress + backups) as a separate, itemized line item alongside the existing flat license fee, roughly at cost or a modest markup, instead of folding it into one uplifted price.

Neither option changes any existing tier or vertical-module price elsewhere in this document — this is additive, future-hosting content only. Cloud figures are illustrative/comparative research, generically attributed to 2026 public cloud pricing comparisons, not a quote from a specific vendor's pricing page.

Why ServiceNow's number looks small until you scale it

ServiceNow's $11,000 headline is a per-user starting price — it grows with every analyst added, plus a separate device-based component, which is exactly why real deployments land at $40K–$120K/year. VulnHunter's price is fixed by environment size with unlimited users, so it doesn't recreate that same growth curve as a security team scales.

10Launch readiness — what has to be true to sell this

The pricing and SLA above are the real, decided commercial model. Honoring the SLA table in §3 operationally requires standing up:

Support operations

A ticketing system, on-call rotation for Enterprise's 24×7 tier, and a documented escalation path — none of this exists yet as a staffed function.

Uptime monitoring & a status page

Real external uptime monitoring and a public status page are what make the uptime commitment in §3 measurable and credible to a paying customer — not yet built.
