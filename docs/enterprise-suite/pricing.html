VulnHunter Pricing

Enterprise vulnerability management and remediation, licensed annually by environment size — unlimited users, every tier — backed by a real support SLA. Normalized to cost-per-asset (the metric this whole market actually bills on), VulnHunter runs 3–5x cheaper than the least-expensive named alternative, and its own unlimited-user pricing model doesn't grow with headcount the way a per-seat platform does. See §02 for the numbers, sourced.

03Licensing options

Every option below is a real, current pattern in this market — matched to VulnHunter's own structure, not invented from nothing.

Term-based subscription (standard)

Annual, auto-renewing. Every platform researched for §02 has moved to this model — nobody in vulnerability management sells a perpetual license anymore, and VulnHunter doesn't either.

Metered per-asset (alternative to a flat tier)

$6.50/asset/year, no tier commitment, 500-asset minimum — for an environment whose size varies too much for a flat cap to fit well. Still cheaper per-asset than every named competitor in §02.

Scan-engine add-on (Standard tier only)

$6,000/year adds the OpenVAS/GVM scan engine to Standard without a full Professional upgrade — the same "core platform + priced add-on module" pattern CrowdStrike uses for Falcon Spotlight. Included by default in Professional and Enterprise.

Multi-year commitment discount

10% (2-year) / 15% (3-year), prepaid or annual invoicing — deliberately more modest than the 38–45% Qualys reportedly discounts at 3-year/10,000+-asset scale (§02's sourcing), since VulnHunter's list price is already positioned well below that comparison point.

Why ServiceNow's number looks small until you scale it

ServiceNow's $11,000 headline is a per-user starting price — it grows with every analyst added, plus a separate device-based component, which is exactly why real deployments land at $40K–$120K/year. VulnHunter's price is fixed by environment size with unlimited users, so it doesn't recreate that same growth curve as a security team scales.

09Launch readiness — what has to be true to sell this

The pricing and SLA above are the real, decided commercial model. Honoring the SLA table in §3 operationally requires standing up:

Support operations

A ticketing system, on-call rotation for Enterprise's 24×7 tier, and a documented escalation path — none of this exists yet as a staffed function.

Uptime monitoring & a status page

Real external uptime monitoring and a public status page are what make the uptime commitment in §3 measurable and credible to a paying customer — not yet built.
